Start with a demo, not a blank page

  • lamp.space.swri.edu/cumulative-maps-all
  • The tedious stuff is the hard part: the gaps, the handholding, the map projection details.
  • It is easier to see a demo and decide that A is better than B than to start from zero.
  • AI helps us leapfrog the setup so we get to discovery faster.
  • Instead of saying, “let us get started,” we are already on “what is next?”

What it costs

  • SwRI has a GitHub Copilot subscription (ask ITC) you can use in your IDE.
  • That is about $20 per seat each month, plus usage.
  • I use about 22k credits per month, which works out to roughly $110.
    • This talk was 122 credits, which is about $0.61.
  • That is tiny compared with how far it gets us, compared to the time otherwise.

What happens after the AI

  • Then the work shifts to connecting it with the actual data sources.
  • You have to think about security, especially when a file upload could wipe a database.
  • That is where containers help: package the tool, ship it to better computers, and make it more usable and accessible.
  • We also pull in ideas from tools and workflows that already work elsewhere.

The gotchas

  • There is certainly over-optimization and hype in the market.
  • OpenAI, Anthropic, and others will all tell you the next model is wildly better.
  • In practice, I have found Claude is often better for GUI work, so I will switch to that, but then I usually switch back to Auto.

Takeaway

AI helps us skip the tedious first pass so we can spend more time on discovery, architecture, and the parts that actually move the work forward.
