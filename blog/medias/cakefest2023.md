# CakeFest 2023 (Sep 30, 2023) - Agile Deployment of CakePHP in Hybrid Environments

At CakeFest 2023, I presented how we evolved CakePHP application deployment for space science workloads at Southwest Research Institute.

The core idea: as spacecraft and sensor data volumes increased, we stopped forcing all data through a single traditional stack and moved to a deployment model that puts software closer to the data.

## Talk focus

- Deploying modular CakePHP applications across on-prem infrastructure, HPC, and AWS
- Keeping Docker and "traditional server" deployment paths available in parallel
- Scaling long-running work with queue workflows
- Using practical tooling for dependency and repository management in enterprise/on-prem environments
