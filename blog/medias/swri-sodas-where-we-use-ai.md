# SwRI SODAS: Where We Use AI

This short internal talk covered where AI helps most in my day-to-day workflow: getting past the tedious first pass so more time can go toward discovery, architecture, and real integration work.

## Highlights

- Start with a demo, not a blank page.
- Use AI in the IDE to accelerate prototyping while still reviewing changes carefully.
- Save human attention for the parts that matter most: data connections, security, deployment, and fit-for-purpose design.
