# CakeFest 2025 (Aug 10, 2025) - Power-Ups for Modern CakePHP Applications

At CakeFest 2025, I presented a set of practical "power-ups" we have been applying to CakePHP applications in active production.

The theme was simple: improve apps in steps. Start where you are, add capability where it helps most, and avoid over-engineering.

## Talk highlights

- Logging evolution: file logs to centralized and contextual error workflows
- Faster data workflows using query improvements and database features
- WebAssembly and PyScript experiments for browser-side scientific tooling
- Selecting the right level of complexity for your team and users
