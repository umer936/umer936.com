## Overview

For our UT Austin EE445L final project, we built a custom 10-keyless RGB keyboard from the ground up. The goal was to create a practical keyboard that supported normal typing and modifiers while also adding portable macro recording that is stored on the keyboard itself.

## What We Built

- **Custom hardware:** Designed the circuit, had the board fabricated, and assembled the keyboard using Gateron Brown switches and keycaps.
- **Individually addressable RGB backlighting:** Enabled per-key lighting control and effects.
- **USB interface:** Implemented USB communication and worked through USB 3 signal integrity and impedance-matching challenges.
- **Macro recording mode:** Supports standard key behavior (including common modifiers like Control and Caps Lock) plus user-recorded macros that can type a stored phrase or sequence.
- **Onboard persistence:** Macros remain with the keyboard, so behavior moves with the device across computers.
